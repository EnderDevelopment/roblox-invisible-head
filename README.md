# InvisibleHead

InvisibleHead is a Roblox script designed to hide the head from other players while keeping hats and head accessories visible. This script is specifically for R6 characters and works within Roblox executors.

## Install

1. Download the script file `HideHeadFromOthers.server.lua`.
2. Place the script in the `ServerScriptService` of your Roblox game.

## Use

1. Ensure your Roblox game is using R6 characters.
2. Run the game.
3. The script will automatically hide the head from other players while keeping hats and head accessories visible.
